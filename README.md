# SSC CHSL Tier 1 – 28-Day Preparation Hub & Todo Tracker

An interactive, responsive web application and daily todo list designed specifically for SSC CHSL Tier 1 aspirants.

## Features
- **Fixed Daily Schedule (9:00 AM – 9:00 PM)**: Real-time schedule tracker with live slot detection and focus timer.
- **Complete 28-Day Syllabus**:
  - **Week 1 (Days 1–7)**: Build Your Basics
  - **Week 2 (Days 8–14)**: Arithmetic & High-Weightage Topics
  - **Week 3 (Days 15–21)**: Advanced Topics & Complete Syllabus
  - **Week 4 (Days 22–28)**: PYQs, Sectional Mocks & Full Tier 1 Simulation
- **Subject-Wise Checklists**: Quantitative Aptitude (Maths), General Intelligence & Reasoning, English Language, General Awareness (GK & Science).
- **Daily Question Target Counters**: Keep track of the recommended daily targets (Maths: 25–30, Reasoning: 25–30, English: 25–30, GK: 20–25).
- **Mistake & Error Notebook**: Log incorrect questions and tag reasons (Concept gap, Calculation mistake, Option confusion, Guessing).
- **Integrated Focus Pomodoro Timer**: Preset durations (45m Practice, 60m Concepts, 15m Breaks) with audio chimes.
- **Auto-Save & Local Backup**: Progress persists across sessions via browser LocalStorage. Includes JSON export and restore.
- **Dark/Light Mode & Printable Checklist**: Ready for both screen study and physical paper checklist printing (`Ctrl+P`).

## How to Open
1. Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, or any modern web browser.
2. No internet connection or installation required — works 100% offline.
